# WageWise

A standalone UK wage and budgeting calculator.

Open `index.html` in a browser or deploy the repository directly with Vercel using the **Other** preset, root directory `./`, and no environment variables.

## Included

- Annual, monthly, weekly and hourly wage inputs
- 2026/27 England, Wales and Northern Ireland Income Tax estimate
- 2026/27 employee Class 1 National Insurance estimate
- Gross and take-home yearly, monthly, weekly, daily and hourly figures
- Editable monthly expenses and real hourly income
- Custom budget planner with a 50/30/20-inspired template
- Savings-goal calculator
- Local browser storage
- Responsive desktop and mobile design

Figures are estimates and do not currently include Scottish Income Tax, pension contributions, student loans, salary sacrifice, tax-code changes, multiple jobs or other payroll deductions.
